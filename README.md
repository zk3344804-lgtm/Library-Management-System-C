# 📚 Library Management System in C

A simple console-based Library Management System developed in C to manage books and book issue records using file handling.

## 📌 Features

- Add new books
- View available books
- Remove books
- Issue books to students
- View issued books
- Automatically store book and issue records in files
- Automatically record the date of adding/issuing books

## 🛠️ Technologies Used

- C Programming
- Structures
- Functions
- File Handling
- Binary File Operations
- Date and Time Functions

## 📂 Project Overview

This project is a console-based Library Management System developed using C.

It allows the user to add books, view available books, remove books, issue books to students, and view issued book records.

The project uses file handling to store records permanently.

## 📁 Files Used

- `main.c` – Main source code
- `books.txt` – Stores book records
- `issue.txt` – Stores issued book records
- `temp.txt` – Temporary file used while removing a book
